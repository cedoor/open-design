# open-design

Personal OpenDesign workspace — a vendored copy of the [OpenDesign](https://github.com/nexu-io/open-design) harness (skills, design systems, templates) plus a custom `designer` agent.

## Setup

```sh
bun install
```

## Usage

Open with OpenCode and use the `designer` agent. Update the vendored harness with:

```sh
bun run harness:update
```
